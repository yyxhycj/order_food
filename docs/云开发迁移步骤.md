# 云开发迁移步骤

日期：2026-05-14

## 当前落地状态

项目已经切换为微信原生小程序 + CloudBase 的第一版主线：

1. `project.config.json` 已配置 `cloudfunctionRoot: "cloudfunctions/"`。
2. `app.js` 启动时初始化 `wx.cloud` 并调用 `login` 云函数。
3. 页面通过 `services/` 访问云数据库和云函数。
4. `app.json` 只注册菜谱、想吃请求、我的、轻量管理相关页面。
5. 旧 Express/MySQL、商品、购物车、订单、盲盒、提醒、游戏化入口已退出主线。

## 微信开发者工具步骤

1. 打开项目并确认 AppID 正确。
2. 在“云开发”面板中开通环境。
3. 上传并部署以下云函数：
   - `login`
   - `createRecipe`
   - `updateRecipe`
   - `deleteRecipe`
   - `createRequest`
   - `updateRequestStatus`
   - `toggleFavorite`
4. 如需管理员白名单，在云函数环境变量配置 `ADMIN_OPENIDS`，多个 openid 用英文逗号分隔。
5. 创建云数据库集合：
   - `users`
   - `categories`
   - `recipes`
   - `requests`
   - `favorites`
   - `comments`
6. 在 `categories` 中可先插入默认分类；若未插入，前端会使用本地默认分类兜底。

## 验收路径

1. 首次打开小程序，`login` 自动创建 `users` 记录。
2. 发布一条菜谱，确认写入 `recipes`。
3. 首页展示已发布菜谱。
4. 从详情页收藏菜谱，确认 `favorites` 写入并更新 `favoriteCount`。
5. 朋友发起“想吃”请求，确认写入 `requests` 并更新 `wantCount`。
6. 作者在“收到的想吃”中推进状态。
