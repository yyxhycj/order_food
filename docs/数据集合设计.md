# 数据集合设计

日期：2026-05-14

## users

```js
{
  openid: String,
  nickname: String,
  avatarUrl: String,
  bio: String,
  role: 'user' | 'admin',
  status: 'active' | 'disabled',
  recipeCount: Number,
  requestCount: Number,
  createdAt: Date,
  updatedAt: Date,
  lastLoginAt: Date
}
```

## categories

```js
{
  name: String,
  description: String,
  icon: String,
  sort: Number,
  status: 'active' | 'inactive',
  createdAt: Date,
  updatedAt: Date
}
```

索引：

- `status` 升序、`sort` 升序，用于首页分类展示。

## recipes

```js
{
  title: String,
  description: String,
  coverImage: String,
  images: Array,
  categoryId: String,
  authorOpenid: String,
  authorName: String,
  ingredients: [{ name: String, amount: String }],
  steps: [{ text: String, image: String, sort: Number }],
  cookingTime: Number,
  difficulty: 'easy' | 'medium' | 'hard',
  tags: Array,
  tips: String,
  status: 'draft' | 'published' | 'hidden' | 'deleted',
  viewCount: Number,
  favoriteCount: Number,
  wantCount: Number,
  commentCount: Number,
  createdAt: Date,
  updatedAt: Date
}
```

索引：

- `status` 升序、`createdAt` 降序，用于首页最新菜谱和管理列表。
- `status` 升序、`categoryId` 升序、`createdAt` 降序，用于分类筛选。
- `status` 升序、`favoriteCount` 降序，用于收藏排序。
- `status` 升序、`wantCount` 降序，用于想吃排序。
- `status` 升序、`viewCount` 降序，用于浏览排序。

## requests

```js
{
  recipeId: String,
  recipeTitle: String,
  recipeCoverImage: String,
  requesterOpenid: String,
  requesterName: String,
  authorOpenid: String,
  authorName: String,
  reason: String,
  status: 'pending' | 'accepted' | 'preparing' | 'done' | 'declined' | 'cancelled',
  statusText: String,
  note: String,
  createdAt: Date,
  updatedAt: Date,
  handledAt: Date
}
```

数据量明显增长后建议索引：

- `requesterOpenid` 升序、`createdAt` 降序，用于“我发出的想吃”。
- `authorOpenid` 升序、`createdAt` 降序，用于“收到的想吃”。

## favorites

```js
{
  recipeId: String,
  userOpenid: String,
  createdAt: Date
}
```

业务约束：同一个 `userOpenid + recipeId` 只应收藏一次，由 `toggleFavorite` 云函数控制。

数据量明显增长后建议索引：

- `userOpenid` 升序、`createdAt` 降序，用于“我的收藏”。
- `userOpenid` 升序、`recipeId` 升序，用于判断是否已收藏。

## comments

第一版已在菜谱详情页开放轻量留言。

```js
{
  recipeId: String,
  userOpenid: String,
  userName: String,
  userAvatar: String,
  content: String,
  status: 'visible' | 'hidden' | 'deleted',
  createdAt: Date,
  updatedAt: Date
}
```

索引：

- `recipeId` 升序、`status` 升序、`createdAt` 升序，用于菜谱详情留言列表。
