# 数据集合设计

日期：2026-05-14

## users

```js
{
  openid: String,
  nickname: String,
  avatarUrl: String,
  bio: String,
  role: 'user' | 'admin',
  status: 'active' | 'disabled',
  recipeCount: Number,
  requestCount: Number,
  createdAt: Date,
  updatedAt: Date,
  lastLoginAt: Date
}
```

## categories

```js
{
  name: String,
  description: String,
  icon: String,
  sort: Number,
  status: 'active' | 'inactive',
  createdAt: Date,
  updatedAt: Date
}
```

## recipes

```js
{
  title: String,
  description: String,
  coverImage: String,
  images: Array,
  categoryId: String,
  authorOpenid: String,
  authorName: String,
  ingredients: [{ name: String, amount: String }],
  steps: [{ text: String, image: String, sort: Number }],
  cookingTime: Number,
  difficulty: 'easy' | 'medium' | 'hard',
  tags: Array,
  tips: String,
  status: 'draft' | 'published' | 'hidden' | 'deleted',
  viewCount: Number,
  favoriteCount: Number,
  wantCount: Number,
  commentCount: Number,
  createdAt: Date,
  updatedAt: Date
}
```

## requests

```js
{
  recipeId: String,

  recipeCoverImage: String,
  requesterOpenid: String,
  requesterName: String,
  authorOpenid: String,
  authorName: String,
  reason: String,
  status: 'pending' | 'accepted' | 'preparing' | 'done' | 'declined' | 'cancelled',
  statusText: String,
  note: String,
  createdAt: Date,
  updatedAt: Date,
  handledAt: Date
}
```

## favorites

```js
{
  recipeId: String,
  userOpenid: String,
  createdAt: Date
}
```

业务约束：同一个 `userOpenid + recipeId` 只应收藏一次，由 `toggleFavorite` 云函数控制。
